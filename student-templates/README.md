# Student workflow templates / 学员 Workflow 模板

Each YAML contains no more than four learner-completion points. The points are intentionally different by module and map to that module's core concepts. Copy them into `.github/workflows/` only in a disposable learner branch, then complete them from the lab instructions.

每个 YAML 最多包含 4 处学员补全点，并且不同模块的补全内容不同，分别对应本模块的核心知识点。只应在学员临时分支中复制到 `.github/workflows/`，然后根据实验手册完成。

The complete solutions are under `answers/`. Do not open that directory during the exercise.

完整答案位于 `answers/`。实验过程中不要打开该目录。
