# Instructor answer key / 讲师答案

This directory contains the complete working versions of the CI/CD YAML and the Composite Action.

本目录保存完整可运行的 CI/CD YAML 和 Composite Action 正确答案。

Do not copy this directory into a learner working branch until the exercise is complete.
学员完成实验前不要查看或复制本目录。

The active `.github/workflows/` files remain runnable so the repository baseline can be validated. Use `scripts/prepare-student-mode.sh` to replace the active files with incomplete learner templates in a disposable training branch.
